# ERC project integration

Independent static apps served from `/proyectos/`. No build or package installation. Original GitHub repositories remain backups and do not automatically synchronize.

- Slang Labyrinth: `/proyectos/slang-labyrinth/`; Three.js r128 CDN, browser speech recognition, browser-local profiles. MIT license retained. Analytics off; admin UI excluded.
- Writing practice: `/proyectos/simulador-escritura/`; deadline-based draft recovery, manual Gmail/download/print, no grading.
- Editorial: `/articulos/`; existing customer-support guide and new summary/opinion practice article.
- Resources: `/recursos/`.

Preview deployment first. Production migration separate. Old-origin localStorage cannot be read from new origin. No automatic migration of student profiles.
